# AnhChat

Aplikasi chat Android milik Anhtronik.

## Fondasi versi 1
- Daftar chat
- Ruang chat
- Kirim pesan lokal
- Status
- Daftar panggilan
- Tombol voice call
- Tombol video call
- Voice note placeholder
- Kirim media placeholder
- Permission kamera
- Permission mikrofon
- Permission kontak
- Permission notifikasi
- Permission internet

## Berikutnya
- Login nomor HP + OTP
- Database realtime
- Chat antar HP
- Grup
- Foto/video/file
- Voice note
- Status 24 jam
- Push notification
- Voice call
- Video call
